# examples/

`CaAlGlass.recipe.json` is a fitted recipe for a 27Al MAS spectrum of a calcium aluminosilicate glass, and `CaAlGlass_fit.png` is the resulting figure. The original dmfit `.fxmla` source file is not distributed, so the recipe serves as a reference for the file format and fitted parameters rather than a runnable demo. Recipes reference their source data by path and SHA-256 hash.
